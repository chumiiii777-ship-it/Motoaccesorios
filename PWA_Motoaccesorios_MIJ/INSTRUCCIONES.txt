APP MOVIL (PWA) - INVENTARIO MOTOACCESORIOS MIJ
================================================

Esta carpeta es la aplicacion completa. Contiene:
  index.html            la aplicacion
  manifest.webmanifest  datos para instalarla como app
  sw.js                 permite que abra sin internet
  icon-192.png, icon-512.png   iconos

PASO 1. PUBLICARLA (solo se hace una vez)
La carpeta debe quedar en internet con direccion https. Elige UNA opcion:

  Opcion A - Netlify (la mas facil, sin cuenta de GitHub)
    1. Entrar a app.netlify.com/drop e iniciar sesion.
    2. Arrastrar la carpeta completa (con todos sus archivos) a la pagina.
    3. Netlify entrega un enlace https. Ese es el enlace de la app.

  Opcion B - GitHub Pages
    1. Crear un repositorio en GitHub y subir estos 5 archivos a la raiz.
    2. Settings > Pages > elegir la rama principal y la carpeta raiz (/root) > Save.
    3. Esperar un par de minutos: GitHub muestra el enlace.

  Opcion C - Render (Static Site)
    1. Subir estos 5 archivos a un repositorio de GitHub.
    2. En render.com: New > Static Site > elegir el repositorio.
    3. Build Command: dejarlo vacio. Publish Directory: .  (un punto)
    4. Create Static Site. Render entrega el enlace https.

PASO 2. INSTALARLA EN EL CELULAR
  Android (Chrome): abrir el enlace > menu de tres puntos > "Instalar aplicacion"
                    (o "Agregar a la pantalla de inicio").
  iPhone (Safari):  abrir el enlace > boton Compartir > "Agregar a pantalla de inicio".
  Queda un icono con el logo; se abre como una app y funciona sin internet
  despues de la primera vez que se abre con conexion.

IMPORTANTE
  - Los datos se guardan SOLO en ese telefono. Cada telefono tiene su propio inventario.
  - Hacer copias de seguridad seguido: menu Mas > Hacer copia.
  - En iPhone, instalar la app ANTES de registrar productos: lo que se guarda
    en Safari no pasa a la app instalada.
  - Si se borran los datos del navegador o se desinstala la app, se pierden los datos
    (por eso la copia de seguridad).

ACTUALIZAR LA APP
  Si se cambia index.html: en sw.js cambiar "mij-inventario-v1" por "mij-inventario-v2"
  y volver a publicar. Los telefonos reciben la version nueva al abrir la app con internet.
